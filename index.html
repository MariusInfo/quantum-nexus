💻 Apple MacBook (macOS)
• Varianta 1 (Instant din Safari / Chrome): În Safari pe MacBook, apasă sus în bară pe File ➔ Add to Dock... (sau în Chrome/Brave apasă pe iconița 📲 Instalează din dreapta barei de adrese). Jocul apare direct în Dock și Launchpad ca aplicație nativă!
• Varianta 2 (Instalator nativ .DMG / .APP): Folosește pachetul Electron / GitHub Actions inclus în proiect pentru a descărca fișierul Quantum-Nexus.dmg pentru Apple Silicon (M1/M2/M3/M4) și Intel.
📱 Apple iPhone & iPad (iOS / iPadOS)
Deschide jocul în Safari, apasă pe butonul Share (Partajează ⬆️) din mijloc-jos și alege „Add to Home Screen” (Adaugă pe ecranul principal). Rulează fullscreen și 100% offline!
🤖 Android (Telefon / Tabletă - APK sau WebApp)
• Direct: Apasă pe meniul ⋮ în Chrome ➔ Instalează aplicația.
• Fișier .APK: Introdu link-ul site-ului pe PWABuilder.com și descarcă gratuit fișierul .apk.
🖥️ Windows PC (.EXE sau Aplicație Desktop)
• Direct din Browser: Apasă pe iconița de instalare din bara de adrese Chrome/Edge.
• Executabil .EXE: Rulează comanda npm run dist:win (sau descarcă .exe din GitHub Actions).
